## API 概览

- `Avatar`（`size`、`shape`、`class`）
- `AvatarImage`
- `AvatarFallback`
- `AvatarGroup`
- `AvatarSize`（`Xs`、`Sm`、`Md`、`Lg`、`Xl`）
- `AvatarShape`（`Circle`、`Square`）
- `avatar_class`
- `avatar_styled_class`
- `avatar_image_class`
- `avatar_fallback_class`
- `avatar_group_class`

## 无障碍说明

当头像本身承担传达用户或实体身份的作用时，请提供有意义的 `alt` 文本；当头像周围的相邻文本已经标明了对应人物或对象的名称时，请使用空的 `alt` 值（`alt=""`）。
